## Questions & Sample Outputs

### Question 1: Basic Calculator (`q1.cpp`)
Write a C++ program to implement a calculator with separate functions to `add`, `subtract`, `multiply`, and `divide`.

* **Requirements:**
  * Prompt the user to enter two numbers and choose an operator (`+`, `-`, `*`, `/`).
  * Handle edge cases such as division by zero.

* **Sample Run 1:**
  ```text
  Enter first number: 12.5
  Enter second number: 2.5
  Enter operator (+, -, *, /): /
  Result: 12.5 / 2.5 = 5
  ```

* **Sample Run 2 (Edge Case):**
  ```text
  Enter first number: 10
  Enter second number: 0
  Enter operator (+, -, *, /): /
  Error: Division by zero is undefined.
  ```
